## 라우터(공유기)란?

집이나 사무실에 인터넷이 들어오면 공유기가 그걸 여러 기기에 나눠줌

```
인터넷 (KT/SKT)
    ↓
공유기 (라우터)
    ├── PC        → 192.168.0.2
    ├── 핸드폰    → 192.168.0.3
    └── NAS       → 192.168.0.4
```

---

## IP 주소 두 종류

**공인 IP** — 인터넷에서 우리 집을 찾는 주소

- 예: `222.234.10.160`
- 전 세계에서 딱 하나
- KT/SKT가 할당해줌

**사설 IP** — 집 안에서만 쓰는 주소

- 예: `192.168.0.x`
- 집 밖에서는 접근 불가
- 공유기가 할당해줌



## DNS와 Routes의 차이

```
DNS: "api.app.com → Cloudflare로 와" (여기까지만)

Routes: "api.app.com 트래픽은
         → app-tunnel로 보내고
         → 거기서 http://app:8080으로 전달해"
```

- DNS = 건물 주소
- Routes = 건물 안 안내데스크 ("이 손님은 3층 301호로")

Routes 설정이 없으면 DNS서버에서도 도메인을 어디로 보낼지 몰라 에러 반환
