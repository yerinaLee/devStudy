## 라우터(공유기)란?

집이나 사무실에 인터넷이 들어오면 공유기가 그걸 여러 기기에 나눠줌

```
인터넷 (KT/SKT)
    ↓
공유기 (라우터)
    ├── PC        → 192.168.0.2
    ├── 핸드폰    → 192.168.0.3
    └── NAS       → 192.168.0.4
```

---

## IP 주소 두 종류

**공인 IP** — 인터넷에서 우리 집을 찾는 주소

- 예: `222.234.10.160`
- 전 세계에서 딱 하나
- KT/SKT가 할당해줌

**사설 IP** — 집 안에서만 쓰는 주소

- 예: `192.168.0.x`
- 집 밖에서는 접근 불가
- 공유기가 할당해줌
