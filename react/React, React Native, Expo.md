- **React** = 화면(UI)을 **"함수"로 만드는** 자바스크립트 라이브러리. 화면 조각 하나하나를 **컴포넌트(함수)** 로 만들고, 그 함수가 화면 모양을 그려냅니다.

- **React Native** = React를 웹이 아니라 **휴대폰 앱(iOS/Android)** 으로 만들게 해주는 도구. 웹의 `<div>`, `<p>` 대신 `<View>`, `<Text>` 같은 모바일 부품을 씁니다.

- **Expo** = React Native 개발을 쉽게 해주는 틀. 이 앱은 그중 **Expo Router**(폴더 구조로 화면 주소를 정하는 방식)를 씁니다.

- 정리: **"함수(컴포넌트)로 화면을 그리고, 폴더 구조로 화면 이동을 정하는 모바일 앱"** 입니다.
