app/(views)/endPoint
: 라우터 진입점 (껍데기)
- components/endPoint 로직을 불러옴


| 폴더                  | 역할                                                                                                                                                                                                                                                                                        |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **app/**            | **화면 주소(라우팅) 전용.** 파일 위치 = 앱의 화면 주소. 대부분 "껍데기"라 짧고, 실제 내용은 `components/`에서 불러와 띄우기만 함                                                                                                                                                                                                     |
| **components/**     | **실제 화면 알맹이(로직 + UI).** 버튼·목록·입력창·API 호출·상태 관리 등 진짜 일하는 코드는 전부 여기                                                                                                                                                                                                                         |
| **contexts/**       | **앱 전체가 공유하는 전역 상태.** 로그인 정보([contexts/AuthContext.js](vscode-webview://0ub649usbh35i1bd53si6vqj3jl7kogaisurctrle382lo3kjsi5/contexts/AuthContext.js)), 전역 팝업([contexts/modalContext.js](vscode-webview://0ub649usbh35i1bd53si6vqj3jl7kogaisurctrle382lo3kjsi5/contexts/modalContext.js)) |
| **src/hooks/**      | **재사용 로직 묶음(커스텀 훅).** 예: 지도 로직 [src/hooks/useMap.js](vscode-webview://0ub649usbh35i1bd53si6vqj3jl7kogaisurctrle382lo3kjsi5/src/hooks/useMap.js), 스크롤 감지 [src/hooks/useTabScroll.js](vscode-webview://0ub649usbh35i1bd53si6vqj3jl7kogaisurctrle382lo3kjsi5/src/hooks/useTabScroll.js)      |
| **utils/**          | **도우미 함수.** 예: 기기 저장소 래퍼 [utils/storage.js](vscode-webview://0ub649usbh35i1bd53si6vqj3jl7kogaisurctrle382lo3kjsi5/utils/storage.js)                                                                                                                                                       |
| **styles/**         | **공용 스타일 모음.** (이 앱엔 CSS 파일이 없고, JS로 스타일을 정의)                                                                                                                                                                                                                                             |
| **babel.config.js** | `@components`, `@contexts`, `@styles`, `@utils` 같은 **경로 별칭** 정의. `../../../components` 같은 긴 경로 없이 import하게 해줌 ([babel.config.js](vscode-webview://0ub649usbh35i1bd53si6vqj3jl7kogaisurctrle382lo3kjsi5/babel.config.js))                                                                  |
